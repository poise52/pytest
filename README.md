# Замер скорости скачивания

Из папки проекта запусти скрипт, подставив прямую ссылку на файл.

```sh
python3 download_speed.py "<URL>"
```

В примере используется тестовый файл размером 1 МиБ. [Файлы OVHcloud](https://proof.ovh.net/files/)

```sh
python3 download_speed.py "https://proof.ovh.net/files/1Mb.dat"
```

Через `uv` с Python 3.15.

```sh
uv run --python 3.15 download_speed.py "https://proof.ovh.net/files/1Mb.dat"
```

Скрипт делает 10 GET-запросов подряд и читает каждый ответ до конца. В консоли выводятся среднее время запроса в секундах, суммарный объём тел ответов в байтах и скорость в Мбит/с.

Скорость считается как `байты × 8 / суммарное время в секундах / 1 000 000`. Время включает подключение, ожидание ответа и чтение тела.
